## Practica 03 - Boceto de Modelo Canvas con Achifyfes

(10 Firmas)



El estudiantes realizara un prompt para solicitar el modelo bussiness canvas para una herramienta multiplataforma que exista o use en su vida cotidianda.





Actividades :



- Elegir la Aplicación Multiplataforma

- Estructrurar el Prompt para la generación del Modelo usando Achify

- Revisar el Modelo Obtenido

- Editar el prompt para mejorar el resultado obtenido

- Documentar y agregar al repositorio en base a los requisitos solicitados (buenas prácticas).
