## Practica02 - Boceto de Arquitectura del Proyecto Integrador con Archify 



Valor: 24 firmas


Fecha límite: 14 de septiembre de 2026



Descripción de la práctica:



En esta actividad se realizará la instalación y configuración de Archify, una herramienta orientada al modelado de arquitecturas de software. También se integrará con Codex mediante ChatGPT para generar un primer modelo arquitectónico interactivo correspondiente al Proyecto Integrador.


Como punto de partida, se utilizará un prompt que describa los principales componentes tecnológicos del sistema y la forma en la que se relacionan entre sí.

## Prompt Utilizado

> [!IMPORTANT]
> ### Initial Architecture Blueprint & Scope
> **Use Archify to create an initial interactive architecture diagram.**
> 
> #### System Stack:
> * **Flutter Mobile App**
>     * ➔ `Keycloak Authentication`
>     * ➔ `FastAPI REST API`
>         * ➔ `PostgreSQL`
>         * ➔ `MongoDB`
>     * ➔ `Leaflet / Maps Service`
> 
> ####  Development Environment:
> * ➔ `Docker`
> * ➔ `Docker Compose`
> 
> #### Source Control:
> * ➔ `Git`
> * ➔ `GitHub`
> 
> #### Required Views & Deliverables:
> * **Mobile client** & **Authentication layer**
> * **API layer** & **Data layer**
> * **External services** & **Development infrastructure**
> * **Main request/data flows** & **Trust boundaries**
> 
> _**Note:** Use an architecture diagram. Generate it as interactive HTML._
